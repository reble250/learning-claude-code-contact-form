# お問い合わせフォーム ブラウザテスト項目

## 概要
- 目的: `docs/テストケース.md`で実施済みのHTTPレベル（curl／tinker）での検証結果を、実際のブラウザ操作で再確認し、スクリーンショットによる証跡を取得する。
- 対象ブラウザ: Google Chrome（最新版）
- 対象環境: `php artisan serve`で起動したローカルサーバー（例: `http://127.0.0.1:8000`）
- 前提データ: `database/seeders/ContactSeeder.php`で投入した100件のダミーデータ、`database/seeders/AdminUserSeeder.php`で作成した管理者アカウント（`admin@example.com` / `password`、環境変数`ADMIN_EMAIL`/`ADMIN_PASSWORD`で変更可）
- 証跡: 各項目で少なくとも1枚、画面全体が分かるスクリーンショットを撮影し、「ブラウザテスト報告書テンプレート.md」の様式に貼り付ける
- 対応関係: No列は`docs/テストケース.md`の対応するNoを併記。境界値テスト（B系）・管理画面のCSVダウンロード（E系）はテストケースにない画面確認項目のため新規に追加した

## 3. 補足
- BF07（XSS対策）は、確認画面でHTMLソースを表示（右クリック→ページのソースを表示、または開発者ツール）し、`<script>`タグがエスケープされたテキストとして出力されていることもあわせて確認しスクリーンショットに含めることが望ましい。
- BB05・BB07は通常のブラウザ操作（`<input type="date">`や`<select>`）では不正な値を直接入力できないため、開発者ツールのDOM編集機能で入力要素の制約を回避するか、フォーム送信前にJavaScriptコンソールから値を書き換えて実施する。実施方法が分かるよう、操作前後の状態がわかるスクリーンショットを残す。
- BE02のダウンロードファイルの中身確認は、ブラウザのスクリーンショットに加えてテキストエディタ等で開いた画面のスクリーンショットも証跡として添付する。
